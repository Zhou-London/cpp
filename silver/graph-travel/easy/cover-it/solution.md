线索在 **⌊n/2⌋** 这个数上。看到"至多一半"，应该想到：能不能把所有点分成两组，让**每一组单独都满足条件**？如果能，两组里必有一组大小 ≤ n/2，输出小的那组就行。

那怎么分？先用一个小例子试试。取一条链 1-2-3-4-5，从 1 开始 BFS，记 `dep[v]` 为 BFS 层数：

```
点:   1  2  3  4  5
dep:  0  1  2  3  4
```

按 dep 的奇偶分成两组：偶数层 {1,3,5}，奇数层 {2,4}。检查一下：

- 只选 {2,4}：1 挨着 2，3 挨着 2，5 挨着 4 ✓
- 只选 {1,3,5}：2 挨着 1，4 挨着 3 ✓

两组都行，输出小的 {2,4}。

为什么这在任意连通图上都成立？关键是 BFS 的一个性质：**每个非根点 v 的 BFS 父节点 p 满足 `dep[p] = dep[v] - 1`**，也就是说 v 和 p 一定属于不同奇偶组。于是：

- 选奇数层：任何偶数层的非根点，它的父节点在奇数层，被覆盖；根（dep=0）的所有邻居都在 dep=1，图连通且 n≥2 所以根至少有一个邻居，被覆盖。
- 选偶数层：任何奇数层的点，它的父节点在偶数层，被覆盖。

注意这里**不需要图是二分图**——同一层内可能有边，我们不在乎，只要求"每个点都有一条边通向另一组"，而 BFS 树边恰好保证了这一点。

所以算法就是：从 1 开始 BFS 求 `dep`，按奇偶分两组，输出人数少的那组。O(n + m)。

几个这题容易踩的坑，提前说一下：

1. t 最多 2·10⁵，每组只清理用到的点（`adj[i].clear()` 对 i=1..n），别每次 `memset` 整个数组。这题 n−1 ≤ m 所以 ∑n 也是有界的，按 n 清理没问题。
2. 输入量大，记得关同步 / 用快读。
3. 你之前的老习惯：Codeforces 上别留 `freopen`。
