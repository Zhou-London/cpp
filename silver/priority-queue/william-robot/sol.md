## 题目转化
本题看似是一个博弈，但可以转化过一个单一的限制。

注意到机器人的行为会不断“抢占”主角想要拿的位置。

例如对于`1, 4, 5, 7, 4, 3, 1`这个数组，如果主角想拿`1, 4, 5, 7 `，那么就会失败，因为一旦拿了1，其后的4就会被抢占。

但是如果主角想拿`1, 5`或者`5, 7`，很容易发现，那都是可以的。

机器人的行为本质是在限制**你没法独吞前k个元素，你必须要和我平分。**

所以，这题目就可以转换成，枚举所有可行的主角选出的集合，通过检查规则**R**:
```
R(k) := 包含的“前k个元素的数量”有没有超过k / 2
```
来判断是否可行，k从1取到数组总长度n。

`1,4,5,7`为什么不行？因为它包含了全部的“前4个元素”，即1，4，5，7。不符合规则R(4)，约束了只能包含 4 / 2 = 2个。`5，7`为什么行？因为它包含了2个“前4个元素”，小于等于限制的2个。

## 优化
接下来通过数据结构来优化尝试一遍扫完就结束。

注意到这个限制是天然符合增量计算的。

从位置0开始从左往右扫，也就是i从左到右，让主角贪心的把位置i的数字给放进集合，注意到因为是从左往后扫的，所以集合的大小恰恰就是“包含的前i个元素的数量”。**放完之后**再检查当前包含的“前i个元素”是不是超过i / 2了，如果超过了说明当前集合不符合规范了，需要把**某个数**给丢出去。

在讨论丢哪个数之前，不妨论证一下为什么这样从左往右扫是没问题的。因为这样在每一步都确保了R(i)，i从1到n，所以构建出的集合就是符合要求的集合。

那么说回丢弃谁，当然是**最小的数**。很经典的贪心最大思想，谁都拿，一旦不符合规则就丢掉最小的。丢弃必须在拿了之后再发生，因为新拿的可能就是新的最小的。

## 实现
实现呼之欲出，用一个最小堆，遍历一遍原输入，先把数字n放进堆，再检查是否符合R(i)，决定是否`pop()`掉最小值。

遍历结束后，对堆中的所有数累加求和，这就是我们要的答案。

## Take-away

**1. 确定性对手 = 没有博弈,只有约束**

这是本题最核心的观念转变。看到"两人轮流取"先别急着想 minimax 或 DP 博弈——先问:**对手的策略是固定的吗?** 机器人永远拿最左,行为完全可预测,那它就不是对手,而是环境规则。真正的问题变成"在这套规则下,哪些结果集合是我可达的",博弈题瞬间退化为构造/优化题。以后遇到"对方按固定规则行动"的题,第一反应应该是刻画可达集合,而不是模拟对抗。

**2. 用"数数"刻画可行性(计数论证)**

我们证明"机器人第 j 次落点 ≤ 2j"时,没有分析任何策略,只数了"到此刻总共消失了几个元素"。这种**不看过程只看总量**的论证非常通用:它给出的必要条件往往就是紧的。你之前在区间、扫描线题里见过的"前缀内事件数不超过某个量"是同一族思想——把一个动态过程的可行性压缩成一组静态的前缀不等式。

**3. 验证充要的标准姿势:小例子双向对拍**

你自己完成的那部分其实是方法论上最值得记的:用 {1,2} 验证"违反约束 ⇒ 抢不到"(必要性),用 {1,3} 验证"满足约束 ⇒ 从左到右能抢到"(充分性)。以后自己推出一个"可行 ⟺ 某条件"的猜想时,就用这套流程:找一个恰好压线的例子和一个恰好越线的例子,手动模拟两边。压线例子还顺便揭示了构造方案(从左到右 = 永远先救最危险的)。

**4. 反悔贪心的适用信号:配额随扫描单调放宽**

小根堆反悔贪心能用,靠的是一个结构性质:**约束(配额 ⌈k/2⌉)随 k 只增不减**。所以"现在合法"就意味着"以后永远合法",弹掉最小值的决定不会在未来反噬。以后判断一道题能不能反悔贪心,就检查这一点:如果前缀约束会收紧,这套做法就不成立了。它和你做过的 Room Allocation 那类题共用"扫描 + 堆维护当前最优集合"的骨架,区别在于这里堆的用途是反悔而不是分配。

**5. 交换论证是贪心正确性的万能螺丝刀**

"如果最优解保留了更小的 x,换成 y 不变差"——这一步你在之前的贪心题里已经用过多次,这题再次出现。值得内化成条件反射:每写一个贪心,逼自己口头说出一遍交换论证,说不通就说明贪心可能是错的。

**6. 老朋友清单又添了一笔**

这题你实际踩的坑:`i + 2 / 2` 的**运算符优先级**——这是"off-by-one"家族的新成员,以后写任何内联算术配额时,要么加括号 `(i + 2) / 2`,要么先算成具名变量;以及第 N 次的 `freopen`。加上潜在的 long long,三个都是你清单上的常客。建议你提交前的自查清单固定为:freopen 对不对平台、和/积会不会爆 int、每个 index 和内联算式代表什么。

一句话浓缩这题:**把确定性对手翻译成前缀约束(计数论证),再用单调放宽的配额喂给反悔贪心。** 下次见到"固定策略的对手"或"前缀配额选数",应该能直接调出这套组合。
