Tarjan 求桥（bridge）的核心思想其实就一句话:**一条边 (u, v) 是桥,当且仅当从 v 的子树里无法"绕回"到 u 或 u 的祖先**。

先建立两个关键概念:

**DFS 树与时间戳**

对无向图做 DFS 会形成一棵 DFS 树,每个点记录一个访问时间戳 `dfn[u]`(第几个被访问到)。非树边在无向图里只能是"返祖边"(back edge),即连回祖先的边——这是无向图 DFS 的重要性质,不存在横叉边。

**low 值**

`low[u]` 定义为:从 u 出发,经过 u 的子树中的点,再最多走**一条**返祖边,能到达的最小 `dfn`。直观理解就是"u 的子树最远能爬回到多老的祖先"。

递推方式:

```
low[u] = min(
    dfn[u],
    low[v]     // v 是 u 的树边儿子
    dfn[w]     // w 是 u 通过返祖边直接连到的点
)
```

**判桥条件**

对树边 (u, v)(v 是儿子):

```
low[v] > dfn[u]  ⟹  (u, v) 是桥
```

意思是 v 的整个子树连一条能爬回 u(或更高)的返祖边都没有,那删掉 (u, v) 后子树就和上面断开了——所以它是桥。注意这里是严格大于,和判割点的 `low[v] >= dfn[u]` 不同。
