## 核心结论

设两棵树的直径分别为 `d1`、`d2`，答案是

```
ans = max(d1, d2, ⌈d1/2⌉ + ⌈d2/2⌉ + 1)
```

## 推导

**1. 新树的直径只有两种来源**

假设连的边是 `(u, v)`，`u` 在第一棵树，`v` 在第二棵树。新树里最长的路径要么不经过新边，要么经过新边：

- 不经过新边：路径完全落在某一棵原树内，最长就是 `d1` 或 `d2`。这部分怎么连都改变不了。
- 经过新边：最长的这种路径是 `ecc1(u) + 1 + ecc2(v)`，其中 `ecc(x)` 表示 `x` 到本树中最远点的距离（偏心距）。

所以新直径是 `max(d1, d2, ecc1(u) + 1 + ecc2(v))`。

**2. 两棵树互不影响，各自最小化 ecc**

`u` 和 `v` 的选择是独立的，所以问题变成：在一棵树里选一个点，使它到最远点的距离最小。这个最小值就是树的半径，对应的点是树的中心。

**3. 半径 = ⌈d/2⌉**

- 下界：设直径两端为 `a`、`b`，对任意点 `x` 有 `dist(x,a) + dist(x,b) ≥ d`，所以两者中较大的那个至少是 `⌈d/2⌉`，即 `ecc(x) ≥ ⌈d/2⌉`。
- 可达：取直径路径的中点 `c`，它的偏心距恰好是 `⌈d/2⌉`。否则若存在点 `y` 使 `dist(c,y) > ⌈d/2⌉`，把 `y` 和离 `c` 较远的那个直径端点接起来，会得到比 `d` 更长的路径，矛盾。

所以不需要真的找出中心，只要求出直径即可。

## 验证样例

- 树 1：最长路径 `2-1-3-4`，`d1 = 3`，半径 2
- 树 2：最长路径 `2-1-3-5-7`，`d2 = 4`，半径 2
- `max(3, 4, 2 + 2 + 1) = 5` ✓

## 实现

求直径用两次 BFS：从任意点出发找到最远点 `a`，再从 `a` 出发找到最远点 `b`，`dist(a,b)` 就是直径。总复杂度 O(n + m)。

## 容易漏的点

不要忘了和 `d1`、`d2` 取 max。比如一棵树是很长的链（`d1 = 100`），另一棵只有两个点（`d2 = 1`），经过新边的最长路径只有 `50 + 1 + 1 = 52`，但原来那条长度 100 的链还在，答案是 100。
