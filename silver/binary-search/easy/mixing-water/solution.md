分两段：先推温度公式 f(k)，再推 k 的公式。

**第一段：奇数杯的温度 f(k)**

设倒了 2k+1 杯，其中热水 k+1 杯、冷水 k 杯。

题目说桶里的温度是"所有杯子温度的平均值"。平均值 = 温度总和 ÷ 杯数。

- 热水贡献的温度总和：(k+1) 杯，每杯 h，合计 (k+1)·h
- 冷水贡献的温度总和：k 杯，每杯 c，合计 k·c
- 总杯数：2k+1

所以 f(k) = ((k+1)h + kc) / (2k+1)。

代样例二检查：h=41, c=15, k=3 → (4·41 + 3·15)/7 = (164+45)/7 = 209/7。

**第二段：什么样的 k 能让 f(k) = t**

把 f(k) = t 写开：

  ((k+1)h + kc) / (2k+1) = t

两边同乘 (2k+1)，去掉分母：

  (k+1)h + kc = t(2k+1)

两边展开：

  kh + h + kc = 2kt + t

目标是把含 k 的项归到一边、不含 k 的归到另一边。把 2kt 移到左边，把 h 移到右边：

  kh + kc − 2kt = t − h

左边提出 k：

  k(h + c − 2t) = t − h

两边除以 (h + c − 2t)：

  k = (t − h) / (h + c − 2t)

分子分母同时乘 −1，变成更顺眼的形式：

  k = (h − t) / (2t − h − c)

代样例二：k = (41−30)/(60−41−15) = 11/4 = 2.75。

**为什么分母一定是正的**

我们只在 t > (h+c)/2 的情况下用这个公式，两边乘 2 就是 2t > h+c，即 2t − h − c > 0。分子 h − t ≥ 0（因为 t ≤ h）。所以 k ≥ 0，是个合法的杯数。

**为什么 2.75 附近的整数就是最优**

f(k) 是随 k 单调递减的：k=0 时是 h，k 越大越接近 (h+c)/2。t 在这条递减曲线上对应的横坐标是 2.75，那 f(2) 比 t 大、f(3) 比 t 小，再往两边走只会离 t 更远。所以候选只有 k=2 和 k=3，比较这两个的差值即可。
