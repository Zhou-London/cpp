## 题目在说什么

**给定：**
- 数组 `a`，长度 `n`
- 数组 `b`，长度 `m`（保证 `m ≥ n`，所以 `b` 更长）

**定义一个函数 f(j)**，其中 `j` 是"偏移量"，取值范围 `0 ≤ j ≤ m - n`：

把 `a` 整体对齐到 `b` 的第 `j+1` 个位置上，逐项作差：

$$c_i = a_i - b_{i+j}$$

然后对这些差做**交替求和**再取绝对值：

$$f(j) = |c_1 - c_2 + c_3 - c_4 + \cdots \pm c_n|$$

直观理解：想象把短数组 `a` 像一把尺子一样，在长数组 `b` 上滑动，每个滑动位置 `j` 都能算出一个数 `f(j)`。

**要做的事：**

有 `q` 次操作，每次操作：
1. 给 `a` 的一段区间 `[l, r]` 里的每个元素都加上一个数 `x`
2. 然后回答：当前所有合法 `j` 中，`f(j)` 的最小值是多少

（注意第一次询问之前也要先输出一次初始答案。）

## 一个小例子

设 `a = [1, 3]`（n=2），`b = [4, 2, 5]`（m=3），那么 `j` 可以取 0 或 1：

- **j = 0**：对齐 `b` 的前两位。`c₁ = 1-4 = -3`，`c₂ = 3-2 = 1`，`f(0) = |-3 - 1| = 4`
- **j = 1**：对齐 `b` 的后两位。`c₁ = 1-2 = -1`，`c₂ = 3-5 = -2`，`f(1) = |-1 - (-2)| = 1`

所以此时答案是 `min(4, 1) = 1`。

## 为什么不能暴力

数据规模大约是 `n, m, q ≤ 10⁵`。每次询问如果对每个 `j` 都重算一遍 f(j)，单次就是 O(n·m)，乘上 q 次直接爆炸。所以核心问题是：**如何让"区间加"和"求 min f(j)"都变快**。

## 核心变形——把 f(j) 拆开

先把定义写成求和形式（用 $(-1)^{i-1}$ 表示正负交替）：

$$f(j) = \left|\sum_{i=1}^{n} (-1)^{i-1} \, c_i\right| = \left|\sum_{i=1}^{n} (-1)^{i-1} \,(a_i - b_{i+j})\right|$$

括号拆开，求和分成两半：

$$f(j) = \left|\underbrace{\sum_{i=1}^{n} (-1)^{i-1} a_i}_{\text{记作 } A} \;-\; \underbrace{\sum_{i=1}^{n} (-1)^{i-1} b_{i+j}}_{\text{记作 } B(j)}\right| = |A - B(j)|$$

就这一步，整道题的结构完全变了。仔细看这两个量：

**A：只和 a 有关，和 j 无关。**
$$A = a_1 - a_2 + a_3 - a_4 + \cdots$$
它就是 a 的交替和，一个**单独的数**。不管 j 滑到哪，A 都不变。

**B(j)：只和 b 有关，和 a 无关。**
$$B(j) = b_{j+1} - b_{j+2} + b_{j+3} - \cdots \quad (\text{共 } n \text{ 项})$$
它是 b 中从位置 j+1 开始、长度为 n 的一段窗口的交替和。j 一共只有 `m - n + 1` 种取值，所以 B(j) 是**一组固定的数**——而且 b 从头到尾不会被修改，这组数**永远不变**！

## 问题瞬间变形

原问题"求 min f(j)"现在等价于：

> 手里有一个数 A（会随修改而变），和一堆固定不变的数 B(0), B(1), …, B(m−n)。
> 每次询问：**这堆数里离 A 最近的那个，距离是多少？**

用之前的小例子验证一下：`a = [1,3]`，`b = [4,2,5]`：
- A = 1 − 3 = −2
- B(0) = 4 − 2 = 2，B(1) = 2 − 5 = −3
- |A − B(0)| = |−2−2| = 4 ✓，|A − B(1)| = |−2−(−3)| = 1 ✓

和第一轮逐项算的结果完全一致。

## 剩下的三个小问题

变形之后，只需要解决：

1. **区间加 x 之后，A 怎么变？**（剧透：变化量简单得不像话，O(1) 就能更新）
2. **怎么快速算出所有的 B(j)？**（不能每个都花 O(n) 硬算，那是 O(nm)）
3. **"一堆固定的数里找离 A 最近的"怎么快？**（经典套路）

## 第三轮：解决前两个小问题

### 问题 1：区间加 x 后，A 怎么变？

给 `a[l..r]` 每个数加 x，A 的变化量是：

$$\Delta A = \sum_{i=l}^{r} (-1)^{i-1} \cdot x = x \cdot \left((-1)^{l-1} + (-1)^{l} + (-1)^{l+1} + \cdots\right)$$

括号里是一串 `+1, −1, +1, −1, …` 交替的数，从位置 l 开始共 `r − l + 1` 项。关键观察：**相邻两项两两抵消**。

- **区间长度为偶数**：完美配对全抵消，ΔA = 0。修改了一大片，A 竟然纹丝不动。
- **区间长度为奇数**：抵消后剩一项，符号由 l 的奇偶决定：
  - l 是奇数（该位置在 A 里带 `+` 号）→ ΔA = +x
  - l 是偶数 → ΔA = −x

所以每次修改只需 O(1)：`A += (r-l+1) % 2 == 0 ? 0 : (l % 2 == 1 ? x : -x)`。

这就是出题人的"障眼法"：看起来吓人的区间修改，因为交替和的抵消结构，实际影响不超过一个 ±x。**根本不需要线段树、树状数组**。

### 问题 2：怎么快速算出所有 B(j)？

B(j) 是 b 中从 j+1 开始、长度 n 的窗口交替和。逐个硬算是 O(n·m)，不行。标准技巧：**前缀和**。

先构造一个"符号固定"的辅助数组：

$$b'_i = (-1)^{i-1} \, b_i \quad \text{即 } b' = [+b_1,\; -b_2,\; +b_3,\; -b_4,\; \dots]$$

对 b' 做前缀和 S，其中 $S_k = b'_1 + \cdots + b'_k$。那么窗口 `[j+1, j+n]` 内 b' 的和就是 `S[j+n] − S[j]`，O(1) 可得。

但有个细节要小心：这个窗口和的符号模式取决于**窗口起点在 b 里的全局奇偶**，而 B(j) 的定义要求**窗口内第一项永远是 `+`**。两者的关系：

- 若 j+1 是奇数（即 j 为偶数）：b' 在窗口内恰好就是 `+, −, +, …`，直接 $B(j) = S_{j+n} - S_j$
- 若 j+1 是偶数（即 j 为奇数）：b' 在窗口内是 `−, +, −, …`，符号整体反了，所以 $B(j) = -(S_{j+n} - S_j)$

统一写就是：

$$B(j) = (-1)^{j} \,\bigl(S_{j+n} - S_j\bigr)$$

拿小例子验算：`b = [4,2,5]`，`b' = [4, −2, 5]`，`S = [0, 4, 2, 7]`（S₀=0）。n=2：
- B(0) = +(S₂ − S₀) = 2 ✓
- B(1) = −(S₃ − S₁) = −(7−4) = −3 ✓

至此：所有 B(j) 可以在 **O(m)** 预处理完毕，且**一劳永逸**（b 不会被修改）。

### 现在的局面

- 手里有 `m − n + 1` 个固定的数 B(j)
- 有一个数 A，每次询问前 O(1) 更新
- 每次要回答：$\min_j |A - B(j)|$

只剩最后一问了：**给定一堆固定的数，反复询问"离某个 A 最近的数"，怎么做到每次 O(log)？** 这是个非常经典的套路：二分搜索

关键前提：**B(j) 按 j 排列时并不是单调的**，你没法直接在"j 的范围"上二分。二分要求有序，所以要先做一步：

## 排序 + 二分收尾

### 正确姿势

我们根本不关心是**哪个 j** 取到最小值，只关心 B 的**取值集合**。所以：

1. 把所有 B(j) 的值存进数组，**排序**（只做一次，O(m log m)）
2. 每次询问时，在有序数组里 `lower_bound(A)`——找到第一个 ≥ A 的位置 `p`
3. 离 A 最近的数只可能是 `B[p]` 或它左边那个 `B[p−1]`（有序数组里，A 的最近邻必然是它插入位置的左右邻居），两者取 `|A − ·|` 更小的

也就是说二分的对象是"**值域**"而不是"j 的下标域"。

### 两个边界坑

- `p == 0`：A 比所有 B 都小，左邻居不存在，只能看 `B[0]`
- `p == size`：A 比所有 B 都大，只能看最后一个
- 数值范围：aᵢ, x 可到 1e9，n 到 1e5，A 最大约 1e14，**必须用 64 位整数**（`long long`），这题 int 溢出是经典 WA 点

### 复杂度总账

| 部分 | 代价 |
|---|---|
| 预处理 A | O(n) |
| 前缀和算所有 B(j) + 排序 | O(m log m) |
| 每次修改更新 A | O(1) |
| 每次询问二分 | O(log m) |
| **总计** | **O(n + m log m + q log m)** ✅ |

### 全题回顾

> 交替和的线性性把 f(j) 拆成 |A − B(j)|：A 被区间修改时因奇偶抵消只动 O(1)；B(j) 用前缀和一次算完且永不变化；于是问题退化为"有序集合里找最近邻"，排序 + 二分即终。

这题的难度全在**第一步变形**——一旦想到拆开，后面每一步都是基础工具。它也是一类套路的代表：*看到"交替和 + 区间修改"，先想抵消；看到"固定集合反复查最近值"，先想排序二分*。
